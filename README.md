# IMAGI3

A browser-native 2D+3D game engine — editor and runtime — that installs as a
PWA on desktop, Android tablet and iPhone. The same projects on every device,
seamless handoff mid-edit, fully functional offline.

The target is not a browser Unreal. It is: _Godot-class 2D authoring plus
competent 3D authoring, in a browser, synced across my devices._

## Status

**Phase 0 (Foundation) complete.** The repository currently contains the build,
test and audit infrastructure plus an application shell that boots. There is no
engine yet — that is Phase 1. See `docs/STATE.md` for exactly where things
stand and `docs/RESUME.md` to pick the work up cold.

## Quick start

```bash
pnpm install          # Node >= 22, pnpm 10.33
pnpm verify           # format, lint, typecheck, unit tests, build
pnpm sweep            # verify, then E2E on three device profiles, then budgets
```

`pnpm sweep` is the full back-to-front sweep and is what must be green before
any phase closes.

## How this repository verifies itself

The audit harness (`tools/audit`) is a package with its own tests and a
**self-test**: for every detector it ships, the self-test plants a specific
defect, asserts the detector catches it, and asserts the same detector stays
green on the clean counterpart. A detector that always failed would pass the
first half and fail the second.

Where a detector has several independent gates, each gate gets its own scenario
in which the other gates stay inside their bounds — so deleting any one gate
makes exactly one scenario start passing, rather than being covered by a
neighbour. This is verified by mutation, not assumed.

The same idea runs in the browser: `tests/e2e/planted-fault.spec.ts` injects a
console error, an uncaught exception, an unhandled rejection and a slow boot
into the real running app, and requires the harness to reject each one — then
requires a clean load of the same app to pass.

Budgets follow the same principle. A budget that is enforced in the current
phase but that no harness measured counts as a **failure**, not a pass. Green
is only allowed to mean "we looked and it was fine".
